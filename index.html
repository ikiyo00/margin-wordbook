阅读台

把章节原文粘进来，选中词或句子即可收录；也可以装书签小工具，在原来的网页上直接划词。

手机上不方便划词时，把微信／网页翻译的结果整段粘贴到下面，点「粘贴解析」也能自动拆出词与释义。

词库

每条记录都带着它出现的那句话，复习时回到原场景。

复习

Leitner 间隔（0 / 1 / 3 / 7 / 14 / 30 天）：先回想它在原句里的用法，再翻面核对。

设置

数据默认只存在本机浏览器；填上 GitHub 信息后，电脑和手机就共享同一个仓库里的词库。

GitHub 数据层

词库存为仓库里的一个 JSON 文件，每次改动都是一次 commit。需要一枚仅对该仓库有 Contents 读写权限的细粒度 token。

应用地址与书签小工具

部署到 GitHub Pages 后把网址填在这里，生成的书签小工具会把划到的词、所在原句和网页出处带回词本。

数据管理

导入会按 id 合并，不会覆盖已有条目。清空只影响本机，不会删除仓库里的文件。

当前数据存于浏览器 localStorage。

四步开始用

1 把整个目录推到 GitHub 并开启 Pages → 2 在「应用地址」填 Pages 网址、生成书签小工具并拖到书签栏 → 3 填仓库信息与 token、勾选自动同步 → 4 在原网页划词收录，或把翻译结果粘贴到「阅读」页解析。

词库是仓库里的 data/vocabulary.json，每次改动一次 commit；Actions 每天早上生成 REVIEW.md 复习清单。电脑和手机打开同一个 Pages 网址，填同一份 token 即可共享词库。
